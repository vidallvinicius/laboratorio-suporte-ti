# GLPI Service Desk

Simulação de ambiente corporativo de Service Desk.

## Tecnologias

- GLPI
- ITIL
- SLA
- Gestão de Incidentes
- Requisições de Serviço

## Atividades

- Cadastro de usuários
- Cadastro de equipamentos
- Criação de chamados
- Classificação
- Priorização
- Diagnóstico
- Resolução
- Encerramento
