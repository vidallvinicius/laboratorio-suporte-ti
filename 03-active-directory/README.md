# Active Directory Lab

Laboratório de infraestrutura corporativa utilizando Windows Server.

## Tecnologias

- Windows Server
- Active Directory
- DNS
- DHCP
- Group Policy
- Windows 11

## Objetivos

- Criar domínio
- Criar usuários
- Criar grupos
- Criar OUs
- Configurar GPO
- Configurar permissões
- Integrar máquinas clientes ao domínio
